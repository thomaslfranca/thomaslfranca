
# Meu Primeiro Projeto

## Objetivos
Este projeto tem como objetivo principal aprender a usar Git e Cursor de forma eficiente. Vou criar um sistema de controle de versão para meus estudos e documentar todo o processo de aprendizado.

## Tecnologias
Vou utilizar principalmente Git para controle de versão e Cursor como editor de código. Também pretendo explorar GitHub para hospedar meus repositórios e colaborar com outros desenvolvedores.

## Cronograma
O projeto será desenvolvido ao longo de 4 semanas, com metas semanais específicas. Na primeira semana, foco em comandos básicos do Git. Na segunda, avançarei para branches e merges.
